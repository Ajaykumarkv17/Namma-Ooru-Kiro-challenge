# Namma Ooru Travel Power

A custom Kiro Power (Kiro University Lesson 5) packaging reusable Tamil Nadu travel-domain
expertise for the Namma Ooru project. It encodes the project's data-quality, grounding, and
source-attribution rules so Kiro produces reliable, source-attributed outputs when curating
destinations, planning itineraries, writing travel content, and analyzing reviews.

## Activation keywords
`Tamil Nadu`, `destination`, `itinerary`, `travel`, `temple`, `trip`, `tourism`.

## Skills
| Skill | Purpose |
|---|---|
| `destination-curation` | Research, structure, and source-attribute TN destinations against the schema; never invent facts. |
| `itinerary-planning` | Build logically ordered multi-day itineraries honoring proximity, hours, durations, interests, budget. |
| `tamil-nadu-travel-content` | Write culturally accurate, grounded travel descriptions and tips. |
| `review-analysis` | Summarize reviews into positives/concerns, clearly labelled as AI-generated. |
